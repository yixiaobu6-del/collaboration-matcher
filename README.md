# 合作匹配器

找人合作总踩坑？
**多维度评估帮你找到靠谱的合作对象。**

[![HTML](https://img.shields.io/badge/打开即用-无需安装-orange)]()

## 避免合作"踩坑"

- **专家档案**：查看合作者历史项目、擅长领域
- **星级评分**：沟通/执行力/创意/可靠性四维评估
- **匹配推荐**：基于反馈分数智能推荐最佳匹配
- **历史追踪**：合作状态管理，复盘合作经验

## 怎么用

打开 `index.html` → 查看专家档案 → 发起合作请求
