# 合作匹配器

> 一人公司合作者/外包团队智能匹配工具，需求分析与模板库

---

## Features / 功能特点

| 功能 | 说明 |
|------|------|
| 需求输入 | 支持需求类型、项目周期、预算范围、质量要求配置 |
| 匹配推荐 | 根据需求自动推荐自由职业者/小团队/专业机构 |
| 优劣分析 | 每种合作类型的优势和注意事项详解 |
| 筛选清单 | 针对推荐类型的重点核对事项列表 |
| 合同要点 | 通用外包合同要点模板清单 |
| 沟通模板 | 首次联系合作方的参考话术 |
| 一键复制 | 模板内容支持一键复制到剪贴板 |
| 数据持久化 | 记录偏好设置和历史匹配结果 |

## Installation / 安装

无需安装，直接在浏览器中打开 `index.html` 即可使用。

```bash
# 克隆仓库
git clone https://github.com/yourusername/partnership-matcher.git

cd partnership-matcher
open index.html
```

## Usage / 使用方法

### 基础用法

1. 打开 `index.html`
2. 在「需求输入」Tab 填写项目需求
3. 点击「开始匹配」查看推荐结果和筛选清单
4. 切换到「模板库」查看和复制合同/沟通模板

### 需求配置示例

```javascript
// 需求配置数据结构
{
  needType: "技术开发",     // 需求类型
  cycle: "1-3个月",        // 项目周期
  budget: "5000-20000",    // 预算范围
  quality: "专业级",       // 质量要求
  createdAt: "2024-01-01"
}
```

### 合作类型对比

| 类型 | 优势 | 注意事项 | 适用场景 |
|------|------|----------|----------|
| 自由职业者 | 成本低、灵活、响应快 | 需要筛选靠谱人选 | 小型项目、紧急任务 |
| 小团队 | 能力互补、有backup | 协调成本、沟通复杂 | 中型项目、多技能需求 |
| 专业机构 | 专业度高、有保障 | 价格昂贵、流程繁琐 | 重要项目、长期合作 |

### 模板库内容

```markdown
# 合同要点清单
1. 工作范围与交付物定义
2. 交付时间与里程碑节点
3. 付款方式与时间节点
4. 修改次数与验收标准
5. 知识产权归属约定
6. 保密条款与违约责任

# 首次沟通模板
您好，我是[姓名]，正在寻找[领域]的合作方。
项目概况：[简述项目]
预算范围：[金额]
期望周期：[时间]
方便进一步沟通吗？
```
